# dev_produccion - Sistema de Gestión de Producción

Este repositorio contiene el código de la aplicación de control de producción de alimentos, empaque, logística y auditoría de calidad de Nutriestacion SAS.

## Estructura de Documentación

Toda la documentación técnica y del negocio se mantiene en este repositorio para asegurar el control de versiones y la alineación con la IA:

*   **[memory.md](file:///c:/Users/jmalt/OneDrive/Documentos/DEV/dev_produccion/memory.md)**: Bitácora de desarrollo y contexto local para la IA (reglas, changelog y decisiones técnicas).
*   **[docs/requerimientos_generales.md](file:///c:/Users/jmalt/OneDrive/Documentos/DEV/dev_produccion/docs/requerimientos_generales.md)**: Requerimientos centrales del sistema, alcance y reglas de negocio.
*   **[docs/arquitectura.md](file:///c:/Users/jmalt/OneDrive/Documentos/DEV/dev_produccion/docs/arquitectura.md)**: Diseño de base de datos, arquitectura de FastAPI y React, y flujos de datos.

## Stack Tecnológico

*   **Frontend**: React + Vite (Tailwind CSS, Shadcn UI)
*   **Backend**: FastAPI (Python)
*   **Base de Datos**: PostgreSQL
*   **Integración**: Odoo ERP (vía XML-RPC)
